# Smart Property Rental Management System

## Problem Statement

Managing rental properties manually using a diary is time-consuming and error-prone. This project aims to digitize tenant records, rent collection, electricity bill tracking, deposit management, and flat availability.

## Objectives

- Manage Buildings
- Manage Flats
- Manage Tenants
- Track Rent Payments
- Manage Security Deposits
- Track Electricity Bills
- Upload Flat Photos
- Generate Reports
- Multi-language Support (English, Hindi, Marathi)
- AI Features (Future)
