# Smart Property Rental Management System

## Problem Statement

Managing rental properties manually using a diary is time-consuming and can lead to errors. The system will digitize tenant records, rent management, deposit management, electricity bills, flat availability, and reports.

## Objectives

- Manage Buildings
- Manage Flats
- Manage Tenants
- Manage Rent
- Manage Deposits
- Manage Electricity Bills
- Upload Documents
- Generate Reports
- Multi-language Support
- AI Features (Future)
